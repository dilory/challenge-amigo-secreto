Amigo Secreto es una aplicación sencilla e intuitiva que permite a los usuarios ingresar uno a uno el nombre de sus amigos elaborando así una lista de la cual se les permitirá realizar un sorteo para determinar quién es el "amigo secreto" de manera aleatoria.

<h2> 🛠️ Funcionalidades del proyecto </h2> 
<ul>
<li> <strong>Funcionalidad 1:</strong> Agregar nombres de amigos a una lista. </li>
<li> <strong>Funcionalidad 2:</strong> Validación para evitar que se agreguen campos vacíos. </li>
<li> <strong>Funcionalidad 3:</strong> Visualización en tiempo real de la lista de amigos participantes. </li>
<li> <strong>Funcionalidad 3:</strong> Sorteo aleatorio de un amigo secreto. </li>
<li> <strong>Funcionalidad 4:</strong> Mensajes de alerta cuando no hay amigos disponibles para sortear. </li>
</ul>

<h2> ⚡ Tecnologías utilizadas </h2> 
<ul>
<li> HTML5 </li>
<li> CSS3 </li>
<li> JavaScript (DOM, funciones y validaciones) </li>
</ul>

<h2> 🚀 Cómo usar el proyecto </h2> 
<ul>
<li> Clonar este repositorio: https://github.com/dilory/challenge-amigo-secreto.git </li>
<li> Abrir el archivo <mark>index.html</mark> en el navegador. </li>
<li> Escribir uno a uno los nombres de amigos en el campo de texto y presionar "Añadir". </li>
<li> Cuando se hayan agregado todos los nombres participantes, hacer click en "Sortear amigo" para obetener la selección aleatoria. </li>
</ul>
